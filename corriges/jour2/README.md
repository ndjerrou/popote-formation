## Ouvrir le corrigé dans Android Studio

1. Récupérez le dépôt : `git pull` si vous l'avez déjà cloné, sinon **Code → Download ZIP** sur GitHub.
2. **File → Open**, puis choisissez **le dossier de l'appli** (`corriges/jour2/1-Convertisseur`), pas la racine du dépôt.
3. Attendez la synchronisation Gradle, puis **Run ▶**.

Comparez avec votre propre code : les différences sont souvent plus instructives que la solution elle-même.
